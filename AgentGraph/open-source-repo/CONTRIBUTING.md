# Contributing

Thanks for improving Veynod.

1. Open an issue or discussion before a large change.
2. Keep the CLI dependency-free where possible; Node 18.17+ is the floor.
3. Add or update a test under `test/` when behaviour changes.
4. Sign off every commit with the Developer Certificate of Origin:

   ```
   Signed-off-by: Your Name <you@example.com>
   ```

   Use `git commit -s`. By signing off you certify that you wrote the change or
   have the right to submit it under the MIT license.

5. Do not include credentials, tokens or customer data in issues, fixtures or
   logs.

The project is MIT licensed. There is no separate CLA.
