# ADR P6：资源权益与 Agent Poker Arena 的边界和门禁

> 状态：**PROPOSED，等 owner 与法律评审**。任务 `fed-resource-rights-poker-arena-sim-v1`（验收 RR-08 / RFC RR-14）。
> 本 ADR 只决定 R0–R3 的工程边界；R4、R5 的每一项都是 owner 决策，**没有任何静默默认值**。

## 背景

owner 的原始商业设想：联邦内德扑匹配，按 M 约定质押，赢家自动获得输家的合法服务资源，输家不履约就不能开新局，补交后恢复（类似共享单车欠费不能再骑）。这个设想保留为 R4–R5 的**待批准产品概念**。R0–R3 只做无经济价值的模拟，用来验证交互、状态机和公平性。

## 决定（R0–R3 已实现部分）

| # | 决定 | 理由 |
|---|---|---|
| P6-1 | 赢家拿到的是**有界服务请求权**（voucher），不是 token、账号、key、cookie 或订阅。使用方式只有一种：通过现有委派桥向输家发任务，在输家那边用输家自己的资源执行。 | 不转让、不共享任何上游账号；复用 F-07/F-09。 |
| P6-2 | 只有 `MOCK_DEMO` 能托管、质押、发券。`SELF_REPORTED_SUBSCRIPTION` 只能展示；`CONTROLLED_PREPAID`、`AUTHORIZED_PROVIDER_SERVICE` 返回 `FED_E_NOT_AVAILABLE`。数据库 CHECK 也保证 `escrowable = (resource_class = 'MOCK_DEMO')`。 | 自报额度不可核验，个人订阅普遍禁止转售。 |
| P6-3 | SIM、DEMO_M、ARENA_CHIP、M 四个单位互不换算。DEMO_M 用独立账表；筹码不进任何账本；不提供购买、提现、兑换接口。 | 防止“非现金积分”变成可兑现的输赢。 |
| P6-4 | 公平随机：主机先承诺种子，双方再承诺、揭示，牌堆由三方种子派生；结果后公开主机种子，任何人可用动作日志重放。结果由双方托管身份签名（`arena.result`）。 | 可验证；主机无法在看到玩家种子后选牌。主机种子目前明文存库（见“已知风险”）。 |
| P6-5 | 结算与牌局解耦，每局只结算一次（`federation_arena_settlements` 主键 = match_id，账本幂等键）。争议窗口内可暂停；运营人员“维持”或“作废”。 | 与 P5-1 同样的解耦方式。 |
| P6-6 | 违约限制只关闭“开新牌局”的入口，不影响委派、消息、文档或其他功能。只有运营人员确认的违约才限制；事实只开启复核；举报本身不限制。交付、等值补偿（DEMO_M）或裁定后自动解除，并留审计。 | 共享单车模型的模拟；避免自动永久处罚。 |
| P6-7 | 声誉只给多个独立计数（履约、复核中、确认违约次数、争议），`score = null`。 | 复用 P4 的多维原则，不发明总评分。 |
| P6-8 | 新功能两个开关默认关闭，且依赖 `FEDERATION_ENABLED`。 | 生产已开启联邦（2026-11-12 实测），所以必须有独立开关。 |
| P6-9 | **只与同模型类别对局**（owner 2026-11-12）。类别 = 家族 + 代，运营维护；匹配、合同、券、补偿都限定同类；用券发的委派必须在条款里固定类别（`model_policy: exact`）。 | 同类同质，不需要跨模型价格折算；不同模型的产出质量差异不会被折算抹平。注意：同模型不等于同质量，交付仍按验收算。 |

## 门禁：必须由 owner（以及法律意见）决定，未决前不得实现或开启

| 门 | 事项 | 当前状态 | 需要谁 |
|---|---|---|---|
| **G1 / R5** | **任何有经济价值的扑克**：真实 M、可购买或可兑换的权益、真钱、可转让奖励作为质押或奖励 | 禁止。代码里没有任何通道。 | owner + 专业法律意见（赌博/游戏运营许可、经营地与用户地） |
| G2 / R5 | 玩家地域、年龄、身份核验，消费者保护 | 未做 | owner + 法律 |
| G3 / R4 | 上游供应商许可：哪些模型服务允许对第三方提供；**个人订阅（Claude/ChatGPT 消费者计划等）的转售或代用** | 禁止。只允许模拟容量。 | owner + 供应商条款评审 |
| G4 / R4 | 真实计量来源：模型网关或可信适配器；STANDARD_M 的价格快照与归一化公式 | 未做（C5 未变） | owner + 工程 |
| G5 / R4 | 平台经营主体、托管主体、税务、数据保护 | 未定（同 P5 N1/N3） | owner + 法律/财务 |
| G6 / R4 | 取价与兑换：DEMO_M 或未来权益能否与 SIM/钱/其他资源互换 | 禁止 | owner |
| G7 / R4 | 赔付：违约后的真实补偿、可追讨债务 | 不做；本阶段的义务注明“不是法律债务” | owner + 法律 |
| G8 | 经济价值合同的人类门禁与可归责性（谁签、谁担责） | 模拟局由 owner 授权合同哈希；价值合同需重新设计 | owner |
| G9 | 主机种子保管（KEK 封存或外部随机信标）、跨部署主持 | 明文存库，仅模拟可接受 | 工程，进入 R4 前必须完成 |

## 停工条件（任何一条为真即暂停相关功能）

上游账号/cookie 被透传；自报订阅额度生成了可兑现质押；同一权益双花；撤销连接后仍能新执行；消耗超过硬上限；争议被系统自动判为恶意；有经济价值的筹码进入牌局；公开运营缺地域/身份/法律门禁；无测试证据却宣称可用。

## 回滚

两个开关设为 `false` 即停用所有新路由和后台步骤（返回 404，`advance()` 不做任何事）。迁移 3.99 只新增表，不改动既有表；回滚代码后表可以保留不用，或在确认无数据后手工 `DROP`（顺序见 ICD §10）。
