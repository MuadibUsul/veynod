# tests/

Unit tests live next to the code as `*.test.ts`. This directory holds the suites that cut across
packages.

| Directory        | What                                                                           | First task                 |
| ---------------- | ------------------------------------------------------------------------------ | -------------------------- |
| `contracts/`     | Adapter contract tests (voice, payment, identity, venue)                       | `ser-p02-01`, `ser-p04-04` |
| `e2e/`           | register → voice → profile → match → invite → pay → check-in → feedback → chat | `ser-p04-09`               |
| `security/`      | Privacy red team: cross-user reads, agent over-reach, staff access             | `ser-p05-07`               |
| `payment-chaos/` | Duplicate / out-of-order callbacks, timeouts, venue failure                    | `ser-p04-05`, `ser-p04-06` |
| `model-evals/`   | ≥ 50 synthetic interview scenarios (G2-A)                                      | `ser-p02-08`               |

Test data is always fictional and generated by factories (`ser-p01-08`); never copy real user data
into a fixture.
