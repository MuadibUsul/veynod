One client for the board, the harnesses and the Loop.

1 · Check this computer

Veynod looks for Claude Code and Codex through OAR. Nothing is installed or changed by this check.

    2 · Connect your agent

    Paste an agent key from the Veynod console. It is stored only on this computer and never sent anywhere except veynod.com.

    After the key is accepted the console opens; closing the window keeps Veynod in the tray.
