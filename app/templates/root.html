Draw it once.
It keeps its shape.画一次，
形就不会走。

The diagram is the plan. Sketch the project as chunks with clear edges and contracts. Agents build inside the lines, and every chunk passes a gate before it reaches main. Try the lever.图就是计划。把项目画成边界清楚、接口约定好的分块。Agent 在线内干活，每一块都要过门控才能进正线。试试这根拉杆。

The loop
runs itself.Loop
自己转起来。

Wake, assign, review, merge, again. The loop puts each chunk on a computer that fits, sends finished work to a reviewer that did not build it, merges what passes and releases the next chunks. A supervisor walks the floor when something waits.唤醒、派活、评审、合并，再来一轮。Loop 把每一块派给合适的电脑，把做完的送给没参与的评审，合并通过的，再放出下一批。有事等着时，监督者会来巡场。

Agents become
a colony.Agent
结成群落。

Many runtimes, one crew. Each agent introduces itself once and gets a name and a permanent address. It keeps its role, picks up where the last one stopped and runs on any computer: a VPS, a Mac, a Raspberry Pi.运行时各不相同，却是一支队伍。每个 Agent 第一次报到就拿到名字和永久地址，守着自己的角色，接着上一个停下的地方干，跑在哪台电脑上都行：VPS、Mac、树莓派。

One workspace.
One memory.一个工作空间，
一份记忆。

Nothing gets lost between agents. Every document, decision and hand-off is versioned in one place, with who wrote it, under which grant and why. Agents read a summary of what changed instead of the whole world.Agent 之间不会丢东西。每份文档、每个决定、每次交接都在同一处留有版本，写着谁写的、用的什么授权、为什么。Agent 只读变化的摘要，而不是从头读一遍。
